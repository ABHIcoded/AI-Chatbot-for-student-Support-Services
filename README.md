# GNIOT AI Student Support Portal

An AI-powered student support portal built using **Flask, MySQL, and Gemini AI**. The system allows students to log in securely, view attendance, check fee status, see upcoming exams, and interact with an intelligent AI chatbot that answers academic queries using student data.

## Features

* Secure student login
* Personalized dashboard
* Attendance management
* Fee status tracking
* Exam schedule
* AI chatbot powered by Gemini AI
* Responsive UI with modern design
* MySQL database integration

## Technology stack

* Python (Flask)
* MySQL
* HTML, CSS, JavaScript
* Bootstrap 5
* Google Gemini API

## Installation

```bash
git clone https://github.com/CODSOFT-ai/AI-Chatbot-for-student-Support-Services.git
cd AI-Chatbot-for-student-Support-Services
pip install -r requirements.txt
python3 app.py
```

Open: `http://127.0.0.1:5000`
